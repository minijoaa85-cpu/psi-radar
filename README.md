# PSI Radar V1.2 — Power Semiconductor Intelligence Radar

공개 자료 기반 한국어 전력반도체 주간 기술 모니터링 웹 플랫폼. GaN (40%) > SiC (30%) > IGBT (10%) = UD/UG SGT (10%) = SJ MOSFET (10%).

**Web:** https://minijoaa85-cpu.github.io/psi-radar/  
**Workflow:** https://github.com/minijoaa85-cpu/psi-radar/actions/workflows/weekly.yml

## 기능

- GaN·SiC·IGBT·SGT·SJ MOSFET 뉴스와 학술지 DOI 메타데이터 수집 및 원문/DOI 연결
- 뉴스 최근 8일, 학술지 최근 45일 검색 / 관련 없는 GAN·SiC 소재 논문 최소화
- 한국어 제목 및 기술 해설(선택적 OpenAI API)
- 뉴스는 **제목 기반 요약**(사실 확정 금지), 학술지 논문은 **공개 초록 기반 요약**(원문 검증 전 표시)
- 중요도·기술별 필터, 한국어·원문 제목 검색, Device Physics 참고 내용 접기/펼치기
- 중복 자료 캐시 재사용 / AI 비용 및 API 오류 모니터링
- 기업 재무 및 제품 Datasheet 비교 기능은 후속 개발이며 현재 데이터가 없음을 표기

## OpenAI API 연결 — 소유자가 최초 1회 설정

1. https://platform.openai.com/ 에서 API 계정/프로젝트를 확인하고 **새 API 키를 발급**합니다. ChatGPT Plus 요금과는 별개입니다.
2. OpenAI Platform 프로젝트의 **Usage / Limits 및 Budget** 설정에서 월별 비용 예산과 알림을 설정하세요. 로컬 추정 한도는 계정 전체 청구 상한이 아닙니다.
3. GitHub **Settings → Secrets and variables → Actions → New repository secret**에 아래 이름으로 API 키를 등록합니다.
   - Name: `OPENAI_API_KEY`
   - Secret: 발급한 키 값 (**대화창, GitHub 코드, README, 이슈에 붙여 넣지 마세요**)
4. GitHub Actions → `PSI Radar - Weekly Collect and Deploy` → **Run workflow**를 실행합니다.
5. 배포 후 대시보드 **Data Quality** 탭에서 AI 호출 횟수·캐시·추정 비용을 확인합니다.

**API 키 없이도 정상 작동합니다.** 공개 뉴스와 서지 정보를 수집하고 웹 화면을 배포합니다. AI 요약은 API 키가 연결된 뒤 정기/수동 실행에서만 활성화됩니다.

## 주간 업데이트 및 운영 기간 (2026-11-11 기준)
- 일정: `cron: 0 21 * * 0` — 한국시간 **매주 월요일 06:00**, UTC 일요일 21:00. 실행이 늦어지거나 건너뛰어질 수 있습니다.
- 다음 정기 예정일: **2026년 11월 16일(월) 06:00 KST**. 자동 종료일은 설정되어 있지 않습니다.
- GitHub 공개 저장소에서 **60일 동안 저장소 활동이 없으면** GitHub가 scheduled workflow를 비활성화할 수 있습니다. 자동 수집이 계속 성공하면서 커밋되는지 정기 확인하고, 중단 시 Actions에서 다시 활성화하세요.
- GitHub Pages는 마지막 배포를 보여 주므로 자동 수집이 끊겨도 사이트가 정상처럼 보일 수 있습니다. 항상 데이터 갱신 일자를 확인하세요.
- `site/data.json`은 최신 결과로 갱신하지만 `site/reports/`에 주차별 요약 보고서를 별도로 누적 보관합니다. 전체 원문 및 모든 데이터를 영구 보존하는 기능은 아닙니다.
- API 키, 결제 크레딧, GitHub 계정과 Actions, GitHub Pages, 외부 출처 서비스 상태에 따라 실제 업데이트가 중단될 수 있습니다.

## IGBT 수집 품질 점검 (2026-11-11)
- IGBT는 뉴스 검색·Crossref 논문 검색·대시보드 카테고리에 추가됨.
- 기존 데이터에는 IGBT 0건이었음: 카테고리 추가와 실제 자료 확보는 별개.
- 뉴스 검색어를 IGBT Power Semiconductor, Power Module, Trench, RC-IGBT, Field-Stop로 확장함.
- 최근 7일간 IGBT 관련 뉴스가 없으면 최근 30일 검색을 추가로 수행하고, **최근 30일 참고**로 별도 표기함.
- GitHub Actions의 코드 변경(push) 실행은 비용 방지 및 경합 회피를 위해 데이터 JSON을 저장하지 않으므로, **최신 IGBT 건수 확인 시 Actions → Run workflow를 수동 1회 실행**해야 함. 주간 예약 실행도 저장함.
- Crossref 논문 45일 수집은 아직 커버리지가 제한되어 있으며 학술지 검색 고도화는 별도 과제.

## V0.3: 학술 논문 / 제조사 기술정보 수집 고도화
- 기존 뉴스 최근 7일 및 기존 Crossref 학술지 45일 검색 유지
- **IGBT, SGT, SJ MOSFET**에 대해 최근 **365일 논문 메타데이터**를 Crossref 및 OpenAlex에서 다중 쿼리로 검색
- 두 서비스의 결과는 DOI를 기준으로 통합·중복 제거하고, 원문을 열어 확인할 수 있도록 링크를 유지
- IEEE TED, JEDS, TPEL, Solid-State Electronics 등을 관심 학술지로 기록 (특정 저널로만 검색을 제한하지 않음)
- 논문 초록이 확보된 경우에만 AI의 초록 기반 요약을 허용하며 원문 검토 여부를 명시
- OpenAlex 기본 조회는 추가 API 키 없이 시도하며, `OPENALEX_API_KEY`는 필요할 때만 별도 GitHub Secret으로 제공 (현재 필수 아님; 제공업체의 이용량/과금조건은 별도)
- AI 호출 상한은 기존 실행당 12회 / 추정비용 $0.02 그대로 유지; 우선순위가 같은 IGBT·SGT·SJ 논문에 각 최대 1회씩 AI 분석 슬롯 우선 배정
- 제조사 공식 링크 참고 섹션: Infineon IGBT7, ROHM SJ MOSFET, Toshiba DTMOS
- **중요:** '수집된 자료'는 1년치 연구 참고자료를 포함하므로 매주 신간 건수와 다릅니다. Overview의 주간 핵심 업데이트에는 최근 8일의 자료만 표시합니다.
- API 메타데이터는 학술지의 실제 발행일·인용·초록 등록 상황에 따라 누락되거나 부정확할 수 있습니다. 논문 원문을 자동으로 무단 다운로드하지 않습니다.
- 현재 코드 Push 이벤트는 자료를 배포만 하고 `site/data.json` 커밋을 건너뜁니다. **새 논문 검색 결과를 저장소에도 저장하려면 Actions에서 Run workflow를 1회 실행**해야 하며, 그때 API 키가 있는 경우 제한된 AI 요약 호출이 발생할 수 있습니다.

## V0.3.1: 2026-11-12 수집·분석 안정성 개선
- Crossref 집중 검색 9회에서 기술군별 1회(최대 3회)로 줄이고, 429 응답 시 최대 3초를 기다려 한 번 재시도합니다. 다시 429가 발생하면 해당 실행의 나머지 Crossref 집중 검색을 중단하고 OpenAlex 결과를 활용합니다.
- 45일짜리 기본 Crossref 검색은 GaN / SiC에만 유지하고, IGBT / SGT / SJ는 집중 학술 검색으로 처리합니다.
- 신규 검색이 일부 실패해도 기존 365일 이내의 논문 메타데이터를 가능한 한 유지하고, 화면에는 **이전 수집 정보 유지**로 표시합니다. 해당 표시는 최신 검증 완료를 의미하지 않습니다.
- OpenAI 응답에 JSON 생성 여유를 주도록 최대 출력 토큰을 480으로 설정하고, 답변은 간결한 3필드 JSON으로 제한했습니다.
- 실패한 AI 응답은 HTTP 코드 / 잘린 JSON 등 안전한 오류 유형별로 집계하며 원문, API 키, 비밀 값은 로그에 기록하지 않습니다.
- AI 호출 12회, 총 입력 12,000토큰, 출력 3,600토큰, 실행당 비용 추정 $0.02 예산은 유지합니다. **실제 처리 건수는 토큰 예산에 따라 12건 미만일 수 있습니다.**
- GitHub Pages 아티팩트 등록 지연으로 인한 일시적 배포 오류를 줄이기 위해 업로드 후 8초 간격을 뒀습니다.
- Data Quality 탭에서 요약 성공/실패, 오류 유형, 이전 논문 보존 건수를 확인할 수 있습니다.
- 코드 push에 의한 CI 검증에서는 AI 호출을 0으로 유지합니다. 실제 AI 결과는 다음 정기/수동 갱신에 검증하며 API 잔액을 추가로 건드리지 않습니다.

- 후보 자료는 **논문 메타데이터 / 공식 제조사 발표 / 제목 기반 일반 뉴스**로 출처 구분을 유지합니다. 제목·발행일·근거 URL을 표시하며 허구의 연구 성과·공정 Recipe를 생성하지 않습니다.
- 함께 표시되는 실제 제품은 **같은 전력 소자 기술군의 제조사 제품 참고자료**로 한정됩니다. 제품의 실제 결함 원인, 특정 현상의 해결 성능, 논문과 제품 간 기술 이전 관계를 입증한다는 의미가 아닙니다.
- 한 화면에 **주제 한 줄 해설 → 관련 근거 최대 6건 → 공식 제품 자료 최대 6건**을 표시합니다. 주제를 바꾸면 즉시 업데이트됩니다.
- `site/topic_map.json`은 기존 공개 뉴스·논문 수집이 완료된 이후 새로 생성되며, 정기·수동 실행 시 기존 주간 이력과 함께 저장됩니다. 코드 push 실행에서는 최신 데이터로 사이트 아티팩트만 업데이트하며 AI 추가 사용을 하지 않습니다.
